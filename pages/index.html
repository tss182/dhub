Built for Speed & Safety

Designed for engineers who live in the keyboard and need confidence when touching production.

🛡️

PROD / DEV Safety Tags

Visual tab tinting, Read-Only locks, and Dangerous Query Guards intercepting UPDATE/DELETE without WHERE.

🔐

SSH Tunnel & OS Keyring

Connect through bastion hosts with TOFU known_hosts verification and native OS Keyring secret storage.

⚡

Smart Monaco Query Console

Context-aware SQL autocomplete, parameter binding, editable single-table query results, transaction control (AUTO/MANUAL), and dialect formatting.

📊

Inline Grid & DML Preview

Multi-range selection, inline editing, duplicate rows, Copy As SQL INSERT/UPDATE/UPSERT/JSON, Value Viewer panel, and DML preview before applying.

🗺️

ER Diagrams, DDL Viewer & Schema Diff

Interactive ER canvas, visual Table Structure Designer, database/schema/table DDL viewer, and cross-connection Schema Diff migration generator.

🔄

Workspaces & Auto-Updater

Save multi-tab workspace sessions, export portable JSON config backups, and install GitHub Releases updates in-app.

📈

Split-Tab View & Result Charts

Side-by-side split workbench tabs and interactive chart visualizations directly from query or table results.

💾

Backup, Restore & Auto CLI Tools

Native database backup and restore with real-time progress, cancellation, and automated client tool download/management.

👥

User & Privilege Manager

Inspect and manage database users, roles, account locks, and object/admin privileges across supported engines.

Keyboard-First Workflow

Ctrl/⌘ + PSearch Everywhere across connections
Ctrl/⌘ + EnterExecute query at cursor / selection
Ctrl/⌘ + SApply staged grid changes
Ctrl/⌘ + DDuplicate selected row(s)
Ctrl/⌘ + TToggle Value Viewer (Views) panel
Ctrl/⌘ + Shift + CCopy As (CSV, JSON, SQL INSERT/UPSERT)
Shift + Alt + FFormat SQL in active dialect
Ctrl/⌘ + IOpen Settings & Preferences
Ctrl/⌘ + HOpen Help & User Guide

Why DHub?

Positioned between heavy enterprise suites and paid proprietary clients.

DBeaver

Comprehensive, but runs on Java/JVM with heavy memory usage and slower startup.

TablePlus

Fast and clean native UI, but closed-source with paid license limits on tabs and connections.

DHub

Native Go + Wails v3 speed, small footprint, 100% open-source (GPLv3), zero telemetry, and no artificial limits.
